# Proactive Agent Research Environment: Simulating Active Users to Evaluate Proactive Assistants

## Why It Matters

Pare provides an environment-level way to test proactive assistants against active users rather than static prompts.

## Proactivity Signal

The agent must decide when to intervene, execute, or stay silent while the simulated user continues acting in a multi-app environment.

## Evaluation Setup

Pare models digital applications as finite-state machines and evaluates proactive behavior in closed-loop tasks with active user simulation.

## Key Limitations

The environment is simulated and simplified compared with real desktop or web accounts. User behavior realism is the main constraint.

## Use For

Use this for closed-loop proactive policy evaluation, intervention timing, and multi-app simulation.
