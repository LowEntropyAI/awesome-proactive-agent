# SKILL0: In-Context Agentic Reinforcement Learning for Skill Internalization

## Why It Matters

SKILL0 is adjacent to proactive-agent research because proactive assistants need reusable skills that can be acquired, internalized, and reused without hand-coded procedures.

## Proactivity Signal

The paper is not mainly about when to intervene. Its relevance is skill internalization: an agent can improve future autonomous behavior from task experience.

## Evaluation Setup

The paper evaluates in-context agentic reinforcement learning for skill acquisition and transfer, including zero-skill inference settings.

## Key Limitations

It should be treated as agent-learning infrastructure rather than a direct proactive-assistance benchmark.

## Use For

Use this for skill learning, self-improving agents, and reusable capability acquisition that can support proactive systems.
