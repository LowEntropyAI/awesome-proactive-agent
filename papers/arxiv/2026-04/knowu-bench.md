# KnowU-Bench: Towards Interactive, Proactive, and Personalized Mobile Agent Evaluation

## Why It Matters

KnowU-Bench is one of the most complete benchmarks for personal mobile agents because it combines proactivity, personalization, execution, consent, and rejection handling.

## Proactivity Signal

The agent must infer preferences, decide when to ask or act, and respect user acceptance or rejection during mobile tasks.

## Evaluation Setup

The benchmark runs in Android-emulator-style environments with user logs, preferences, app states, proactive tasks, and interaction constraints.

## Key Limitations

The environment is still controlled and emulator-based. Real phone deployment would add privacy, latency, notification, and app-account complexity.

## Use For

Use this for evaluating personalized mobile agents, consent-aware proactive execution, and rejection-aware behavior.
