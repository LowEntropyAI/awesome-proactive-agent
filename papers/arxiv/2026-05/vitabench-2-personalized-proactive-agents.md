# VitaBench 2.0: Evaluating Personalized and Proactive Agents in Long-Term User Interactions

## Why It Matters

VitaBench 2.0 makes long-term personalization measurable across extraction, use, update, and proactive acquisition of missing information.

## Proactivity Signal

The agent must detect missing information during decision making and proactively acquire it from the user or environment while maintaining user preferences over time.

## Evaluation Setup

The benchmark uses long-term user interaction sequences and supports multiple memory settings, including full context, agentic memory, and RAG-style memory.

## Key Limitations

Even strong context access may not reflect real deployment constraints such as privacy policies, noisy histories, or user fatigue.

## Use For

Use this for long-term personalization, memory-interface evaluation, and proactive missing-information acquisition.
