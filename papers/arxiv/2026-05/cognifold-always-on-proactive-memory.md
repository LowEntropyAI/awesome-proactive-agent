# CogniFold: Always-On Proactive Memory via Cognitive Folding

## Why It Matters

CogniFold moves proactivity into the memory layer: the agent does not only retrieve memory, it continuously organizes experience so intents can emerge.

## Proactivity Signal

The memory system folds streaming events into concepts and surfaces proactive intent when concept clusters become dense enough.

## Evaluation Setup

CogEval-Bench evaluates proactive concept emergence and cognitive-structure formation, alongside standard memory benchmarks.

## Key Limitations

The paper focuses on memory structure rather than user-facing timing, consent, or action execution. The link from surfaced intent to safe behavior remains open.

## Use For

Use this for always-on memory, graph-memory architectures, and proactive intent emergence from event streams.
