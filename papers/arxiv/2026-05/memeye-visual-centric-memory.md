# MemEye: A Visual-Centric Evaluation Framework for Multimodal Agent Memory

## Why It Matters

MemEye is valuable because many proactive multimodal agents fail before action selection: they cannot remember visual evidence at the right granularity.

## Proactivity Signal

The proactive relevance is memory readiness. The agent must preserve visual state and temporal changes so future assistance can be grounded in correct evidence.

## Evaluation Setup

The benchmark evaluates multimodal long-term memory, visual evidence retrieval, temporal state tracking, and diagnostic failure modes.

## Key Limitations

It is a memory benchmark, not a full proactive-intervention benchmark. It does not directly test whether or when the agent should interrupt.

## Use For

Use this for visual long-term memory, multimodal state tracking, and diagnosing perception-memory bottlenecks in proactive agents.
