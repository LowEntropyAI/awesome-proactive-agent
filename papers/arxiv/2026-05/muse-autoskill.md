# MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation

## Why It Matters

MUSE-Autoskill is useful infrastructure for proactive agents because long-lived assistants need to create and manage skills as user needs evolve.

## Proactivity Signal

The work is not primarily about user-facing interruption. Its proactive relevance is self-evolution: the agent can create and reuse skills before future similar tasks arrive.

## Evaluation Setup

The system evaluates skill creation, memory, management, transfer, and reuse across agent tasks.

## Key Limitations

It does not directly evaluate hidden user intent, timing, consent, or user acceptance. It is best read as skill-memory infrastructure.

## Use For

Use this for self-evolving agents, skill lifecycle management, and reusable agent capabilities that support proactive workflows.
