# ToolCUA: Towards Optimal GUI-Tool Path Orchestration for Computer Use Agents

## Why It Matters

ToolCUA is relevant because proactive computer-use agents often need to choose between GUI actions and direct tool/API calls.

## Proactivity Signal

The paper is not mainly about proactive user assistance. Its relevance is path orchestration: deciding how an agent should act once a task or inferred intent is available.

## Evaluation Setup

The work studies GUI-tool orchestration and agentic reinforcement learning for choosing efficient action paths across GUI and tool interfaces.

## Key Limitations

It does not address whether the agent should initiate the task, when to interrupt, or how to handle user consent.

## Use For

Use this for computer-use execution strategy, GUI-tool routing, and MCP/tool orchestration in proactive-agent systems.
