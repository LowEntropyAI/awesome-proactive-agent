# π-Bench: Evaluating Proactive Personal Assistant Agents in Long-Horizon Workflows

## Why It Matters

π-Bench is one of the strongest benchmarks for personal-assistant proactivity because it separates hidden-intent resolution from final checklist completion.

## Proactivity Signal

The agent must infer and resolve hidden user intents from profiles, files, workspace state, and long-horizon context before the user spells them out.

## Evaluation Setup

The benchmark contains persistent personal workspaces and long-horizon workflows. It reports Proc for proactive intent resolution and Comp for final task completion.

## Key Limitations

The benchmark is still curated and does not fully capture live notification timing, emotional cost, or real account permissions.

## Use For

Use this for hidden-intent evaluation, personal assistant workflows, and long-horizon proactive benchmark design.
