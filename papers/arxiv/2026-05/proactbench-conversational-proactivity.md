# ProactBench: Beyond What The User Asked For

## Why It Matters

ProactBench isolates conversational value that is not captured by instruction following: noticing a grounded implication the user never explicitly requested, including after the apparent task is already complete.

## Proactivity Signal

The benchmark scores three trigger phases: `EMERGENT` for a need implied by one detail, `CRITICAL` for synthesis across disclosed details, and `RECOVERY` for forward-looking help after task completion. Generic offers and restatements fail.

## Evaluation Setup

The released corpus has 198 curated dialogues and about 624 trigger rubrics per evaluated model. Across 16 models, the best Recovery pass rate is 37.2%; 14 models pass fewer than 20%, and Recovery correlates substantially less with standard capability benchmarks than the earlier phases.

## Key Limitations

Personas, conversations, trigger points, and most scoring are generated by LLMs, with limited crowd-worker validation. Offline evaluation reuses histories produced with one curation model, so a more proactive response cannot reshape later turns as it would online.

## Use For

Use this for implicit-need surfacing, post-completion assistance, grounded proactive dialogue, phase-specific failure analysis, and separating proactive value from generic helpfulness.
