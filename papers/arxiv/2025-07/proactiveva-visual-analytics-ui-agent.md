# ProactiveVA: Proactive Visual Analytics with LLM-Based UI Agent

## Why It Matters

ProactiveVA brings proactive assistance into visual analytics, where users can get lost in complex tools even when they know the broader analysis goal.

## Proactivity Signal

The UI agent monitors visual analytics interaction logs, recognizes when the analyst may need help, and proactively provides context-aware suggestions or guidance.

## Evaluation Setup

The paper builds design requirements from a formative study of help-seeking behaviors, implements a perception-reasoning-acting UI agent pipeline in two visual analytics systems, and evaluates it with algorithm evaluation, case and expert study, and user study.

## Key Limitations

The system is specialized for visual analytics workflows, and the paper focuses more on assistance design and user experience than on reusable benchmark comparability across general GUI agents.

## Use For

Use this for proactive assistance in complex analytical tools, intervention timing from interaction logs, and human-centered design requirements for GUI-based proactive agents.
