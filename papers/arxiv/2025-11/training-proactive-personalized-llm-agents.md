# Training Proactive and Personalized LLM Agents

## Why It Matters

This paper makes proactivity trainable through explicit interaction objectives rather than treating it as a prompt-only behavior.

## Proactivity Signal

The agent must recognize underspecified prompts, ask useful low-effort questions, and adapt its actions to user preferences.

## Evaluation Setup

UserVille turns software-engineering and deep-research tasks into interactive environments with LLM-based user simulators. PPP optimizes productivity, proactivity, and personalization.

## Key Limitations

The user side is simulated, so the results may not fully capture real user frustration, timing sensitivity, or trust dynamics.

## Use For

Use this for multi-objective RL, proactive clarification training, and personalization-aware agent evaluation.
