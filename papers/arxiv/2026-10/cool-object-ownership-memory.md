# COOL: Curiosity-Driven Object Ownership Learning for Personalized Robotic Assistance

[Primary source](https://arxiv.org/abs/2610.09358) · Checked 2026-10-08 · CoRL 2026 per arXiv comment. Review depth: abstract and arXiv metadata; no experiments rerun.

## Why It Matters

Personalized robotic help needs evidence about which objects belong to whom, including when observations have become stale.

## Proactivity Signal

COOL learns ownership from human-object interaction histories and uses curiosity-driven collection to visit informative locations and refresh long-term spatial memory.

## Evaluation Setup

The abstract reports offline experiments, ablations, and real-world ownership-conditioned navigation and task execution. The arXiv comment states accepted to CoRL 2026.

## Key Limitations

Self-directed observation refresh is internal initiative; ownership-conditioned commands do not establish spontaneous human-facing need discovery. Acceptance is recorded according to the author-supplied arXiv comment, not an independently checked proceedings page.

## Use For

Use for active context refresh, ownership grounding, and personalized embodied memory.
