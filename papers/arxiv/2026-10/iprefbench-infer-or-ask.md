# iPrefBench: A User-Centric Benchmark for Personalized Mobile Use Agents

[Paper](https://arxiv.org/abs/2610.34735) · First posted 2026-10-26 · Checked 2026-10-31. Review: primary method/protocol and linked artifacts; no rerun.

## Why It Matters

Tests the boundary between personalized inference and asking for genuinely missing requirements.

## Proactivity Signal

Underspecified tasks separate history-inferable requirements from ask-only information. Agents can query an interactive simulated user while acting in an executable iOS environment.

## Evaluation Setup

130 tasks across 26 apps share a coherent persona with 3,051 historical activity events. Seven frontier agents are evaluated on personalized task completion and user-agent interaction, not action completion alone.

## Key Limitations

A single constructed persona and simulated user limit conclusions about diverse real users or longitudinal personalization. User-initiated tasks with proactive clarification are not query-free assistance; this is not a streaming-video benchmark.

## Use For

Mobile-agent infer-versus-ask evaluation. No public implementation or dataset files were verified from the inspected paper links; do not treat an executable evaluation description as a released environment.
