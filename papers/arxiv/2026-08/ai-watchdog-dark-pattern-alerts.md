# AI Watchdog: Agent Interfaces for Detecting and Defending Against Manipulative Dark Patterns in AI Conversations

## Why It Matters

AI Watchdog studies a sidecar agent that protects the user from the conversational system itself. Its preregistered experiment also provides a useful negative result: raising awareness and changing behavior are not the same outcome.

## Proactivity Signal

The browser interface monitors a live AI conversation, classifies each turn for five dark-pattern categories, and proactively displays warnings without requiring the user to notice or query the manipulation first.

## Evaluation Setup

An open-weight turn-level classifier supports the interface, and a five-condition between-subjects study with 150 participants varies warning timing and cognitive forcing. Just-in-time warnings without cognitive forcing reduce compliance with manipulated recommendations from 71.7% to 53.7%, while explicit flagging and post-task awareness remain low.

## Key Limitations

The study covers a bounded set of scripted dark patterns and short experimental interactions. The only significant behavioral reduction appears in one configuration, so the results do not justify general claims about lasting resistance, real-world classifier accuracy, or local privacy guarantees.

## Use For

Use this for proactive safety sidecars, warning-timing design, manipulation detection, and evaluations that separate recognition, trust, and behavioral resistance.
