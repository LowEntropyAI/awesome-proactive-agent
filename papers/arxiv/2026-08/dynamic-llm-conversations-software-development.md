# On the Prospects of Dynamic LLM Conversations in Software Development

## Why It Matters

This longitudinal study tests whether lightweight interventions into developer–LLM chats help or disrupt realistic project work. It provides a useful counterweight to benchmark-only claims about proactive coding assistance.

## Proactivity Signal

Students in the proactive condition receive follow-up suggestions and tailored advice inserted into their LLM conversations, while context-aware and control conditions isolate the effect of different conversation augmentations.

## Evaluation Setup

The four-month study follows third-semester computer science students building a full-stack web project under context-aware, proactive, or no-intervention conditions. Interaction logs and surveys show no major detectable differences in measured interaction patterns and a trend toward higher satisfaction in the proactive condition.

## Key Limitations

The intervention is deliberately minimal, the population is students, and reported effects are trends rather than strong causal performance gains. The study does not establish improved code quality, productivity, or long-term expert-developer outcomes.

## Use For

Use this for field evaluation of proactive IDE dialogue, conservative intervention design, longitudinal user studies, and evidence that user satisfaction and observable interaction patterns should be measured separately.
