# ProactiveEval: A Unified Evaluation Framework for Proactive Dialogue Agents

## Why It Matters

ProactiveEval provides one of the clearest decompositions of proactive dialogue evaluation, separating target planning from dialogue guidance.

## Proactivity Signal

The model must identify useful conversational targets and guide the user toward them through multi-turn proactive dialogue.

## Evaluation Setup

The benchmark contains 328 environments across six dialogue domains and evaluates 22 LLMs with task-specific judge prompts and metrics.

## Key Limitations

The benchmark relies on synthetic environments and LLM-as-judge evaluation. It does not test live users, GUI actions, or long-term memory.

## Use For

Use this as the primary reference for proactive dialogue evaluation and for comparing target planning versus guidance ability.
