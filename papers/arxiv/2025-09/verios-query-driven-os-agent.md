# VeriOS: Query-Driven Proactive Human-Agent-GUI Interaction for Trustworthy OS Agents

## Why It Matters

VeriOS is important because it treats proactivity as restraint and trust calibration, not only as doing more for the user.

## Proactivity Signal

The OS agent proactively queries the user when GUI execution is risky, ambiguous, or untrusted, rather than blindly continuing autonomous action.

## Evaluation Setup

The paper evaluates OS-agent behavior under trusted and untrusted GUI conditions, including step-wise success and human-query behavior.

## Key Limitations

The work focuses on query-driven safety for OS agents and does not fully solve broader personalization, long-term memory, or interruption-cost modeling.

## Use For

Use this for consent-aware GUI/OS agents, proactive confirmation, and human-in-the-loop trust calibration.
