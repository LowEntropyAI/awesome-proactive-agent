# Ψ-Bench: Evaluating Persona-Sensitive Influencing in Persuasive Dialogues

## Why It Matters

Ψ-Bench evaluates whether agents can personalize persuasive dialogue rather than applying the same influence strategy to every user.

## Proactivity Signal

The agent uses a user profile to choose arguments, tone, and dialogue strategy that proactively fit the simulated client's persona.

## Evaluation Setup

The benchmark covers debate, counseling, and everyday request scenarios with simulated clients and profile-conditioned judges.

## Key Limitations

Persuasion is a high-risk domain. The benchmark is useful for personalization research, but real deployment requires strong safety and consent boundaries.

## Use For

Use this for persona-sensitive dialogue, proactive personalization, and evaluating profile use in persuasive interactions.
