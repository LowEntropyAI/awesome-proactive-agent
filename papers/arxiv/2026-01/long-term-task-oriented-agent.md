# Long-term Task-oriented Agent: Proactive Long-term Intent Maintenance in Dynamic Environments

## Why It Matters

This paper makes long-term intent maintenance explicit: a proactive agent must monitor conditions and resume tasks when the world changes.

## Proactivity Signal

The agent generates monitoring conditions from prior dialogue and proactively follows up when dynamic environment events satisfy those conditions.

## Evaluation Setup

ChronosBench evaluates intent-conditioned monitoring and event-triggered follow-up in dynamic task-oriented dialogue environments.

## Key Limitations

The benchmark is synthetic and mostly dialogue-driven. It does not directly handle GUI execution, real calendars, or user-controlled consent flows.

## Use For

Use this for long-horizon task threads, reminder-style proactivity, and event-triggered agent follow-up.
