# MagicGUI-RMS: A Multi-Agent Reward Model System for Self-Evolving GUI Agents via Automated Feedback Reflux

## Why It Matters

MagicGUI-RMS is adjacent to proactive agents because it improves the feedback loop needed for GUI agents to evolve without constant human labels.

## Proactivity Signal

The paper is not primarily about user-facing proactivity; its proactive relevance is automated feedback reflux that lets agents improve from trajectories and reward signals over time.

## Evaluation Setup

The system combines domain-specific and general reward models to evaluate GUI-agent trajectories and feed improved data back into training.

## Key Limitations

It should not be treated as a core proactive-assistance paper. It focuses on self-evolution and reward modeling rather than intervention timing or latent user intent.

## Use For

Use this as supporting infrastructure for self-improving GUI agents and automated trajectory evaluation.
