# PIRA-Bench: A Transition from Reactive GUI Agents to GUI-based Proactive Intent Recommendation Agents

## Why It Matters

PIRA-Bench is a clean benchmark for the shift from reactive GUI execution to proactive GUI intent recommendation.

## Proactivity Signal

The agent observes continuous screenshots and recommends likely user intents before receiving explicit task instructions.

## Evaluation Setup

The benchmark uses continuous GUI context streams and evaluates whether models can infer and rank plausible proactive intents.

## Key Limitations

It focuses on recommendation rather than full closed-loop execution, consent, or post-recommendation task completion.

## Use For

Use this for GUI-based latent-intent recommendation and screenshot-stream proactive evaluation.
