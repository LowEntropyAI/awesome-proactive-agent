# PsyProbe: Proactive and Interpretable Dialogue through User State Modeling for Exploratory Counseling

## Why It Matters

PsyProbe makes user-state modeling and information-gap tracking explicit in a sensitive conversational domain. It shows how proactive questioning can be planned from an interpretable psychological profile rather than generated only from the latest utterance.

## Proactivity Signal

The system maintains a structured PPPPPI user state, identifies missing or underexplored dimensions, selects a Motivational Interviewing strategy, and initiates an appropriate exploratory question.

## Evaluation Setup

The paper evaluates automatic ablations and conducts user and expert evaluation with 27 participants in Korean counseling scenarios. The full system improves engagement intention and naturalness over baselines, while a certified counselor assesses core-issue understanding and question behavior.

## Key Limitations

The study covers the exploration phase rather than diagnosis or treatment, uses one language and cultural context, and has a modest participant count. Proactive questioning in mental-health settings also requires stronger clinical safety and escalation protocols before deployment.

## Use For

Use this for proactive dialogue planning, interpretable user-state memory, information-gap tracking, expert evaluation, and safety discussions around high-stakes conversational agents.
