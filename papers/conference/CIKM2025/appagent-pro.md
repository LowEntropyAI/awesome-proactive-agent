# AppAgent-Pro: A Proactive GUI Agent System for Multidomain Information Integration and User Assistance

## Why It Matters

AppAgent-Pro pushes GUI agents beyond single explicit instructions. Its main value for this collection is the idea that a GUI agent can proactively infer deeper information needs and gather cross-domain context before the user asks follow-up questions.

## Proactivity Signal

The system uses the current GUI context and user request to infer latent needs, then searches across multiple applications or information domains to surface useful information proactively.

## Evaluation Setup

The paper evaluates a proactive GUI assistance pipeline for multidomain information integration, comparing the breadth and depth of information returned by proactive versus more reactive GUI-agent behavior.

## Key Limitations

The proactivity is still anchored to an initial user request, so it is less about always-on background intervention and more about anticipatory expansion of an active task. Privacy, notification timing, and long-term preference learning are not the central evaluation targets.

## Use For

Use this paper for GUI-agent workflows where proactive value comes from hidden need inference, cross-app retrieval, and richer task completion before the user has to decompose the problem manually.
