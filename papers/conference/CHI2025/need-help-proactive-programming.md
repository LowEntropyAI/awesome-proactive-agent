# Need Help? Designing Proactive AI Assistants for Programming

## Why It Matters

This is one of the clearest CHI studies on proactive programming assistance. It frames proactive help as an interaction problem: the assistant must decide not only what to suggest, but whether the current moment is appropriate.

## Proactivity Signal

The assistant observes code context, task progress, and developer behavior in an IDE-like programming workflow, then proactively offers help when it predicts the user may benefit from support.

## Evaluation Setup

The paper studies proactive versus reactive programming support in controlled coding tasks, tracking suggestion timing, acceptance, task outcomes, and developer feedback about control, trust, and interruption.

## Key Limitations

The findings come from bounded programming tasks rather than months of real-world development. The work is strongest as evidence for timing and UX trade-offs, not as a complete benchmark for autonomous coding agents.

## Use For

Use this paper to ground intervention-timing discussions for coding assistants, especially when comparing proactive suggestions against user-initiated chat or command-based workflows.
