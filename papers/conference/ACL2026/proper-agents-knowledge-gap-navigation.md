# PROPER Agents: Proactivity Driven Personalized Agents for Advancing Knowledge Gap Navigation

## Why It Matters

PROPER makes a user's knowledge gaps an explicit target for proactive assistance. Instead of choosing between repeated clarification and unchecked contextual guesses, it identifies the task-relevant considerations that the user has not articulated.

## Proactivity Signal

The Dimension Generating Agent (DGA) extracts explicit dimensions from the request and proposes candidate implicit dimensions for unexpressed knowledge gaps. The Response Generating Agent (RGA) selectively incorporates those dimensions to produce a personalized, proactively informative response.

## Evaluation Setup

The paper evaluates PROPER across multiple domains with a gap-aware rubric covering coverage, initiative appropriateness, and intent alignment. It reports gains of up to 84% in single-turn evaluation and consistent wins in multi-turn interactions.

## Key Limitations

The quality of implicit dimensions depends on the underlying model and the task representation. The controlled evaluation does not by itself establish how users will respond to extra proactive information, especially when timing, consent, or interruption cost matter.

## Use For

Use this for knowledge-gap modeling, personalized proactive dialogue, deciding what latent task dimensions to surface, and evaluating initiative beyond answer correctness.
