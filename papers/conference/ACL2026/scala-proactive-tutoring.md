# Let LLM Tutors Ask First: Proactive LLM-Based Tutoring at Scale in a 1,500-Student Online Classroom

## Why It Matters

SCALA provides rare deployment evidence for proactive educational assistance, testing whether likely student questions can be prepared and surfaced before students formulate a request.

## Proactivity Signal

Predictive query management generates likely question-answer pairs ahead of lectures. Students can choose these proactive prompts or switch to ordinary interactive tutoring in the same interface.

## Evaluation Setup

The system was deployed for a semester in an undergraduate Python course with more than 1,500 students. The study measures use of predicted queries, overlap with questions students later ask, and student preferences among response alternatives.

## Key Limitations

The intervention is an optional pre-generated menu rather than a real-time agent deciding when to interrupt. Evidence comes from one course and does not isolate long-term learning gains from interface novelty or self-selection.

## Use For

Use this for deployed proactive tutoring, predictive-query interfaces, low-interruption educational assistance, and field evaluation of user-initiated access to precomputed help.
