# ENPMR-Bench: Benchmarking Proactive Memory Retrieval for Emotional Support Agents

## Why It Matters

ENPMR-Bench expands proactive memory beyond factual recall by asking whether an agent can infer an unspoken emotional need and retrieve the kind of personal memory that would support an empathetic response.

## Proactivity Signal

The target capability maps dialogue context to a latent emotional need, then proactively selects supportive memories without waiting for an explicit retrieval request.

## Evaluation Setup

The benchmark contains more than 1,800 memory-augmented dialogues with structured mappings between emotional needs and supportive memory types. It compares embedding and LLM-driven retrieval methods and evaluates need-memory alignment and downstream empathy.

## Key Limitations

The work evaluates a retrieval component rather than a complete intervention policy. Its need taxonomy and dialogue construction may simplify real emotional states, and empathy metrics do not establish psychological safety.

## Use For

Use this for affect-aware memory systems, latent-need inference, proactive retrieval benchmarks, and separating supportive memory selection from final response generation.
