# ContextAgent: Context-Aware Proactive LLM Agents with Open-world Sensory Perceptions

## Why It Matters

ContextAgent moves proactive agents from desktop-only observation toward open-world sensory context. It is important because many useful proactive services depend on video, audio, notifications, and personal context rather than only the current UI.

## Proactivity Signal

The system extracts multimodal context from wearable-style sensory inputs, combines it with persona/history information, and predicts whether a proactive service should be triggered along with the required tool calls.

## Evaluation Setup

The paper introduces ContextAgentBench for proactive service prediction and tool calling under open-world multimodal context. It compares context-aware proactive pipelines against simpler baselines that lack richer sensory and persona information.

## Key Limitations

The approach depends on reliable perception and rich personal context, which increases privacy and deployment complexity. The benchmark is useful for capability measurement, but real-world acceptability still requires consent, data minimization, and interruption-control studies.

## Use For

Use this paper for wearable assistants, multimodal proactive sensing, context-aware service prediction, and research questions about how much personal context an agent needs before intervening.
