# Hero: Before You Ask

An editorial illustration for the README, not a product demo or a definition of all proactivity. One fictional transit example makes initiative visible: the usual stop closes; a remembered step-free preference shapes the prepared detour. The agent proposes a route, it does not choose for the traveler.

The visual anchor is a dimensional street map. A dashed usual route meets a crossed stop; a solid alternative reaches a flag. Shape and line style carry this distinction without color. Layered paper edges, lit building faces, a river and a restrained mint/lilac wash provide depth. The README uses a landscape desktop composition and a vertical mobile poster. No external images, fonts, animation, or illustration dependencies.

Scope references: README Scope and PERSONAL_AGENTS.md. The location, map, buildings and transit event are illustrative, not sourced geographic data. No method or benchmark claims are depicted.

Only the two README compositions are SVG illustrations. The website instead compares two timelines for the same fictional meeting change. The reactive assistant waits for a request; the proactive assistant prepares a briefing and offers it without sending it. Theme-aware HTML and CSS keep the actor, timing and reader choice visible without an image. Rebuild the README art with `node scripts/build-readme-hero.mjs`.
