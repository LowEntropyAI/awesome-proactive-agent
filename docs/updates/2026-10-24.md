## Existing-work corrections and release checks

- **MemoProAgent / MemoProBench** is the October 21 v2 name of **ProPerAgent / ProPerMem**, not a new paper. The stable local note/website ID is retained. The [official repository](https://github.com/facebookresearch/Memo-Pro-Agent) contains inference, retrieval, evaluation, tests and an RL launcher/reward plugin. [Eval800 histories](https://huggingface.co/datasets/facebook/MemProBench) are publicly listed; an anonymous request for one history file returned HTTP 200 despite stale private-access language in the card. Ego4D videos require separate access. No post-trained checkpoint or complete paper-results recipe was verified.
- **Gander** is now indexed under the current title *Multimodal Duplex Interaction Agent*. [Code](https://github.com/Omni-Interaction-Gander/Omni-Interaction-Agent) includes runtime and training files; the [model index](https://huggingface.co/Gander-Omni/Gander/tree/main) lists ungated Thinker shards and Talker weights. Full training data remains pending. Corrected the note's earlier conflation of roughly 36,000 GUI/video training trajectories with independent evaluation.
- **Clarify or Answer** has an October 20 v2. [Code](https://github.com/zwverse/clarify-or-answer), [ContextClarify JSON/images](https://huggingface.co/datasets/Helen-ZW/ContextClarify), and one [InternVL3-2B GRPO-CR weight file](https://huggingface.co/Helen-ZW/internvl3_2b_clarification_reasoning_grpo) were verified in public indexes. Other listed checkpoints were not individually audited. No new venue acceptance was established.
- **P3IBench:** official repository still contains inference/evaluation scripts, not a training pipeline; dataset JSON/videos are public; the linked author's model list returned no assistant checkpoint.
- **PAM:** repository still contains project-page assets and helper tools, not the full robot implementation or evaluation release.
- **EgoVoice:** project still schedules code, models and data for November 2026.
- **SurgStreamer / StreamingJev:** inspected primary sources did not establish a new public implementation/checkpoint release.

New-artifact cautions: ProactEgoMem distributes metadata and partial annotations, not upstream videos; its annotated dev subset overlaps test. The math-tutoring repository currently has only a README promising future data. ClariEdge's announced dataset API returned HTTP 401 without credentials, so it is not marked available. PITCH, DIVE, PACE, ProMemAgent and ProV-Mem have no verified public artifacts in the inspected links. A file listing is not a successful installation, inference run or reproduction.
