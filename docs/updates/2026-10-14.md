## Streaming-model findings

- **EgoVoice:** direct spoken initiative on first-person streams, not merely full-duplex execution. Its official project page says code, models, and dataset will be released in **November 2026**. The page is reachable, but no current download link was verified.
- **StreamingJev / ProAgent:** a dedicated intervention gate plus a separate response/execution model. The inspected paper and abstract do not establish a canonical public code or checkpoint release.
- **DuplexAct:** included because Help/Safety Interrupt explicitly requires content-grounded intervention during user speech. It is an evaluation suite, not a new model; its remaining turn-taking actions are not all proactive.
- **OneStreamer:** already in the repository. The [official README](https://github.com/MCG-NJU/OneStreamer) adds an October 9 native-streaming InteractionBench score of **36.7**. This is author-reported, not independently reproduced or verified as an all-protocol ranking. Public [Hugging Face metadata](https://huggingface.co/MCG-NJU/OneStreamer-4B/tree/main) still lists ungated weights, while the README's availability table retains a pending marker.

The two new direct systems follow different designs: speech-native Listen/Speak adaptation versus a timing gate with a separate Worker. Comparing their headline scores would be invalid because the tasks and protocols differ.
