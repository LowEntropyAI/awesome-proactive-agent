# November 6 literature scan

Since the [November 2 scan](2026-11-02.md), the arXiv API returned 3,140 records across cs.AI, cs.CL, cs.CV, cs.HC, cs.RO, cs.MA, cs.LG, cs.IR, cs.SD and eess.AS for submissions from October 30, 18:00 UTC to the scan date in Singapore. The newest returned submission was November 5, 18:59 UTC. A keyword screen kept 70 records, all new to the bibliography. A phrase search across all categories found ten more records, none relevant, and Hugging Face Daily Papers for November 2–6 surfaced no further candidates.

Fourteen candidates were read in full from their arXiv HTML or PDF, with every linked repository, dataset and project page opened; the remaining exclusions below were decided from their abstracts. No code was run and no archive was downloaded. Dates below are v1 submissions. Every entry is a preprint unless its arXiv record states otherwise.

## Added papers

| First posted | Work | Role | Scope and reason to include |
|---|---|---|---|
| Nov 5 | [ReferClaw](https://arxiv.org/abs/2611.07683) | Adjacent | Asks which past moment a short egocentric question means, and skips asking when history settles it. Simulated user in main results; 10-person study. |
| Nov 4 | [TurnWise](https://arxiv.org/abs/2611.06728) | Core | Turn-level RL credit for reply-or-wait decisions in streaming video. Code, a 4B checkpoint and training data are public. |
| Nov 4 | [Proactive Dialogue Backdoors](https://arxiv.org/abs/2611.06969) | Supporting | Poisoned fine-tuning hijacks goal-steering counseling dialogue. A risk study with simulated users, not a system that chooses help. |
| Nov 3 | [Pro-Memory](https://arxiv.org/abs/2611.05731) | Core | Stores pending intentions with activation conditions and decides when they become actions. Offline text benchmarks only. |
| Nov 3 | [Cognitive Symbionts](https://arxiv.org/abs/2611.05376) | Core | Position paper: a companion that chooses among silence, hints, questions and action. No system or evaluation; labeled Core because its argument is the unprompted decision itself. |
| Nov 3 | [When to Ask, When to Answer](https://arxiv.org/abs/2611.05517) | Adjacent | Learns when to stop asking in a reference game with a scripted user. |
| Nov 2 | [Omni-Life](https://arxiv.org/abs/2611.02835) | Core | 400 everyday audio-video clips score intervention against silence. 277 clips are generated. |
| Nov 2 | [InteractionBench (voice)](https://arxiv.org/abs/2611.02430) | Supporting | Floor control and staying quiet for seven voice systems. Not the streaming-video InteractionBench already listed. |
| Nov 1 | [SurgStream](https://arxiv.org/abs/2611.01982) | Core | Deadline-windowed alerts and memory for surgical video. Code announced; not the earlier SurgStreamer. |
| Nov 1 | [VagueBench](https://arxiv.org/abs/2611.01878) | Adjacent | Ask-or-answer on queries stripped of details; EMNLP 2026 oral per the arXiv record. Evaluation script and test set public. |
| Oct 31 | [StreamClarify](https://arxiv.org/abs/2611.01263) | Adjacent | Entropy gate for clarifying streaming video questions; WACV 2027 per the arXiv record. Replies are oracle or scripted. |
| Oct 31 | [Is That Clear?](https://arxiv.org/abs/2611.01087) | Adjacent | 180-person study: clarifying questions reduced review time and increased acceptance of wrong answers. |

This scan is clarification-heavy: five of the twelve ask about a request the user has already made, which the Atlas labels Adjacent. All twelve have five-section evidence notes, attributed author figures, bilingual initiative notes and release checks dated November 6. The InteractionBench figure is cropped from PDF page 2 because the HTML version draws it inline rather than as an image.

## Exclusions

| Candidate | Decision |
|---|---|
| CLARA | Clarifies vague robot arrangement commands, but the six-person study reports significance without a test, nothing is released, and the work is dated early 2025. |
| Depth or Description? | "Proactive" means active feature acquisition against data sources; no person receives help. |
| Correct Robots Before They Make Mistakes (PHIL) | A human operator intervenes on a robot policy; the initiative is the person's. |
| When to Ask for Help (aerial refinement); StreamDuo | An agent requests help from another agent or tool for its own task. |
| ActOR | Ambient sensing to plan a humanoid's actions in an operating room; no decision to help a person. |
| OmniScribble | Authors review AI proposals at fixed checkpoints; delegation, not initiative. |
| ReFrame; Decode Before You Hear | Full-duplex compute and latency efficiency. |
| Just-in-Time Skill Retrieval; CoworkOS | Agent skill retrieval and a long-horizon work harness. |
