## Selection and Classification

| Cluster | Selected resources | Selection rationale / evidence |
|---|---|---|
| Runtime activation | OpenClaw, Hermes Agent, Letta Code, Proactivity SDK | Concrete heartbeat, scheduled/event activation, or self-managed cadence and persistent goals. |
| Ambient/personal workflows | MineContext, GAIA, memUBot | Documented contextual delivery, service-triggered work, or recurring workflows. |
| Research agent implementations | Proactive Agent, ContextAgent | Reusable event/sensory-context assistance pipelines with paper evaluation. |
| Product reference | OpenAI dot | Official documentation explicitly describes background research, app-context review, and work between conversations. |
| Scene-triggered interaction | JoyAI-VL-Interaction, MOSS-VL-Realtime, Proact-VL | Model/framework output policy decides speech, silence, or delegation during continuous input. |
| Evidence-conditioned timing | Eyes Wide Open, StreamReady, StreamOV, Response-G1 | Distinct learned readiness, hidden-state, compression, and structured-evidence mechanisms. |
| Query-independent memory | OneStreamer | Memory formation and response-state learning are separated from independent need discovery. |
| Full-duplex interaction | MiniCPM-o 4.5, Gander | Simultaneous perception/output and scene-driven initiative; Gander adds asynchronous reasoning/tool work. |
| Streaming evaluation | StreamGaze, ESTP-Bench, SOVBench, Live Gaming Benchmark; existing OmniMMI/ProReady-QA | Evaluate intent cues, response timing, negative/silence cases, and domain-specific interaction separately. |

Included paper types are method, method + benchmark, system/report, and pure benchmark. StreamGaze is classified as a benchmark and Response-G1 as an inference framework. Mechanism specificity and inspectable evaluation/resources guide selection; no unified experimental score is used across unlike tasks. New cards report evaluation scope without inventing numerical results.

## Source and Release Decisions

- [OneStreamer](https://github.com/MCG-NJU/OneStreamer): preserve the existing paper/card and add official code/data/model links. Its [Hugging Face API/file index](https://huggingface.co/api/models/MCG-NJU/OneStreamer-4B) reports `private: false`, `gated: false`, and four weight files. The GitHub README still says public access pending; that marker appears stale. Public file availability does not substitute for an inference test.
- [Proactivity SDK](https://github.com/refixai/proactivity-sdk): use the canonical repository after the old `refixai/proactivity` URL redirects.
- [JoyAI](https://github.com/jd-opensource/JoyAI-VL-Interaction): prefer the upstream `jd-opensource` repository and current `jdopensource/JoyAI-VL-Interaction` checkpoint over mirrors or the older Preview setup.
- [Proact-VL](https://github.com/microsoft/AnthropomorphicIntelligence/tree/main/Proact-VL): model/data/evaluation sections contain concrete resources despite unchecked items in the TODO block; record this inconsistency instead of inferring that all resources are pending.
- [MOSS-VL](https://github.com/OpenMOSS/MOSS-VL): name the Realtime variant, distinguish available SFT/serving resources from the full-training roadmap.
- [Gander](https://github.com/Omni-Interaction-Gander/Omni-Interaction-Agent): model/runtime links are present; dataset release is described as pending.
- [memU](https://github.com/NevaMind-AI/memU) and [memUBot](https://github.com/NevaMind-AI/memUBot): classify current memory infrastructure and assistant separately.
- [GAIA](https://github.com/theexperiencecompany/gaia) and [Screenpipe](https://github.com/screenpipe/screenpipe): explicitly label source-available/licensing boundaries.
- [StreamOV](https://arxiv.org/abs/2605.25621): primary paper verified; canonical public code/checkpoint was not established in this scan.
- [OpenAI dot](https://help.openai.com/en/articles/20001530-getting-started-with-your-dot): include as an official product reference; do not assign research performance or open-code status from product documentation.
